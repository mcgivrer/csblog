a pocket-sized, text-first computer

Cyberdeck

A small reflective-display handheld built around a Waveshare ESP32-S3-RLCD-4.2 board and a Rii i518BT mini wireless keyboard, running SolarOS — a text-first embedded OS. No backlight, no distractions: files, shell, player, weather, and a photo viewer, all in 1-bit.

01

Hardware

The core is a Waveshare ESP32-S3-RLCD-4.2 board: a 4.2" reflective ST7305 LCD (400×300, monochrome, readable in daylight, no backlight needed), an ESP32-S3 dual-core running at 240MHz, 8MB of PSRAM and 16MB of flash. Input comes from a Rii i518BT, a compact Bluetooth mini keyboard — paired over BLE, no dongle, no cable. The whole thing sits in a 3D-printed case that clips the board and the keyboard together into one slab you can hold in two hands.

Software — SolarOS

The OS is SolarOS, a text-first embedded OS built for this exact class of low-power reflective-display hardware. It ships a shell, a dual-pane file manager, a music player, a weather app and a photo viewer — all rendered in 1-bit, all keyboard-driven. Source and build details live on nilseuropa's GitHub, under the solar_term project.

On screen

Files

Dual-pane file manager — view, edit, copy, move, mkdir, delete and zip, all from the keyboard.

Shell

A proper text shell — ls, navigation, and the usual file operations.

Player

Music player with a cassette-tape UI, playlist support and a volume bar.

Photo viewer

Photos rendered as 1-bit dithered images — surprisingly good detail on the reflective panel.

Heather

Weather via Open-Meteo — temperature and precipitation graphs for the next 24 hours, auto-refresh every 10 minutes.
